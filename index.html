Vorteile & Features

Für Entwickler & Smarthome gebaut

Kein API-Key & kein Limit

Keine Registrierung erforderlich. Alle Feeds sind öffentlich, gecacht und für automatisierte Abfragen optimiert.

Model Context Protocol (MCP)

Integrierter MCP-Server für Claude Desktop und Cursor AI. Dein LLM beantwortet TV-Fragen in natürlicher Sprache.

Home Assistant & Smarthome

Direkt einbindbar als REST-Sensor in Home Assistant, MagicMirror, ESP32 Displays oder Node-RED Dashboards.

Zero-Dependency CLI

Eigenständiges CLI-Tool ohne fremde npm-Abhängigkeiten. Starte sofort mit npx german-tv-guide-api.

Code & Integration

Schnellstart & Anwendungsbeispiele

Wähle dein bevorzugtes Tool für die Integration: 

# Primetime Highlights um 20:15 Uhr abrufen
npx german-tv-guide-api 20-15

# Live im TV: Was läuft aktuell?
npx german-tv-guide-api jetzt

# Nach bestimmten Sendern filtern (z.B. ARD, ZDF, ProSieben)
npx german-tv-guide-api sender ard
npx german-tv-guide-api sender zdf

# Weltweit als globales CLI-Tool installieren
npm install -g german-tv-guide-api
