⚡ Schnellstart mit CLI

Überprüfe direkt in deinem Terminal, was gerade im deutschen Live-Fernsehen läuft:

# Repository klonen
git clone https://github.com/Oleh-kazydub/german-tv-guide-api.git
cd german-tv-guide-api

# Was läuft jetzt im TV?
node cli.mjs jetzt

# Primetime Highlights um 20:15 Uhr
node cli.mjs 20-15

# Nach Sender filtern (z.B. ARD, ZDF, ProSieben)
node cli.mjs sender ard

🤖 Model Context Protocol (MCP Server für Claude & Cursor)

Verbinde dein KI-Modell direkt mit dem deutschen Fernsehprogramm. Trage folgenden Block in deine claude_desktop_config.json ein:

{
  "mcpServers": {
    "fernsehprogramm": {
      "command": "python",
      "args": ["-m", "mcp_server"]
    }
  }
}

Frage Claude einfach: „Was läuft heute um 20:15 auf ProSieben?“ oder „Finde mir heute Abend Krimis im TV“.
